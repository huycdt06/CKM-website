Kết nối GitHub

Dán "khóa truy cập" (Personal Access Token) của GitHub vào đây để lưu thay đổi. Khóa chỉ lưu trên trình duyệt này của bạn.

Chưa có khóa? Tạo một lần tại: GitHub → ảnh đại diện → Settings → (cuối trang) Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Chọn repository huycdt06/CKM-website, quyền Contents: Read and write. Xem chi tiết trong HUONG-DAN.md.
