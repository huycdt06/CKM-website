Kết nối GitHub

Dán "khóa truy cập" (Personal Access Token) của GitHub vào đây để lưu thay đổi. Khóa chỉ lưu trên trình duyệt này của bạn.

Chưa có khóa? Tạo một lần tại: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Chọn repository huycdt06/CKM-website, quyền Contents: Read and write. Xem hướng dẫn chi tiết trong file HUONG-DAN.md.
